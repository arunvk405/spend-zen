# SpendZen Project Rules & Guidelines

## Production & Deployment Directives
1. **Always Use Production Format**: Write clean, modular, and optimized code ready for instant production deployment upon git commit.
2. **Avoid Unnecessary Code**: Do not leave debug console statements, unused imports, or temporary test code in production files.
3. **Strict Type Safety**: Ensure all components and services conform strictly to TypeScript definitions so automated production builds (Vercel / Netlify / Expo Web) compile without errors.
